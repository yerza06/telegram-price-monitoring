# Proposal

## Why

Цены продавцов на Kaspi.kz часто меняются, и следить за ними вручную неудобно. Нужен Telegram-бот, который сам периодически проверяет цену выбранного продавца по товару и сразу сообщает, когда она изменилась.

## What Changes

- Новый Telegram-бот на aiogram в проекте `bot/`, код разложен по пакетам в `bot/src/` (`core/`, `database/`, `handlers/`, `filters/`, `middlewares/`, `keyboards/`, `features/`, `services/`, `common/`), запуск — `uv run python src/main.py`.
- Настройки из переменных окружения и `.env` через Pydantic Settings, сгруппированные по префиксам (`BOT_`, `DATABASE_`, `MONITOR_`).
- `/help` показывает пользователю все доступные ему команды (администратору — и команды администратора).
- Доступ по списку: владелец задаётся через `BOT_ADMIN_ID` в env; он может выдавать и отзывать доступ другим пользователям Telegram. Остальным бот отказывает.
- Пользователь добавляет товар по ссылке на Kaspi и выбирает продавца кнопкой из самых дешёвых в своём городе, смотрит свой список и удаляет товары. У каждого пользователя свой список.
- У каждого пользователя свой город (`/city`, кнопки с крупными городами Kaspi); товар отслеживается в городе, выбранном при добавлении. Для пользователей хранятся имя и username из Telegram.
- Фоновая проверка цен через APScheduler с интервалом (`IntervalTrigger`, не cron). Каждая проверка сохраняется в историю цен.
- Уведомление при любом изменении цены (рост или падение): старая и новая цена, разница в ₸ и %. Отдельное уведомление, когда продавец перестал продавать товар и когда снова начал.
- Хранилище SQLite (SQLAlchemy async + aiosqlite), схема через миграции Alembic.
- Логи: `ENVIRONMENT=local` — читаемый вывод Rich, `ENVIRONMENT=prod` — одна JSON-запись на строку.
- Парсинг Kaspi через httpx + selectolax.

Out of scope (будущие изменения):
- Отчёты: PDF (Quarkdown), выгрузка в Google Sheets, графики Plotly.
- Telegram Mini App (FastAPI + React).
- Выбор любого из 300+ городов Kaspi (в `/city` только крупные города) и перенос товаров при смене города.
- Пороговые/целевые цены и уведомления только о снижении.
- Мониторинг всего каталога продавца.

## Capabilities

### New Capabilities
- `access-control`: кто может пользоваться ботом — администратор из `BOT_ADMIN_ID` и пользователи, которым он выдал доступ; управление списком доступа.
- `product-tracking`: добавление, просмотр и удаление отслеживаемых товаров (товар + продавец) в личном списке пользователя.
- `price-monitoring`: периодическая проверка цены продавца на Kaspi, сохранение истории цен и устойчивость к ошибкам сети и парсинга.
- `price-notifications`: какие уведомления получают пользователи при изменении цены и наличия.

## Impact

- Код: пакеты по слоям в `bot/src/` с точкой входа `bot/src/main.py`; пакет-заглушка `bot/src/bot/` и скрипт `bot` удаляются, проект становится не пакетом (`[tool.uv] package = false`). Миграции Alembic, тесты в `bot/tests/unit/` и `bot/tests/integration/`.
- Зависимости: aiogram, pydantic-settings, sqlalchemy, aiosqlite, alembic, apscheduler 3.x, httpx, selectolax, rich; dev — pytest, pytest-asyncio, ruff.
- Конфигурация (env): `BOT_TOKEN`, `BOT_ADMIN_ID`, `DATABASE_URL`, `MONITOR_INTERVAL_MINUTES`, `ENVIRONMENT`. Город — в базе у пользователя.
- Внешние системы: Telegram Bot API, сайт kaspi.kz (страница товара и JSON-эндпоинт предложений продавцов). Kaspi может поменять разметку или ограничить частые запросы.
